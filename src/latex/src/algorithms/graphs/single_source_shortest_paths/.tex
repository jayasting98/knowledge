\paragraph{Dijkstra's algorithm}

\subparagraph{Standard} Only for graphs where all edges are non-negative

Time complexities:

\begin{itemize}
    \item $O(|E| \cdot T_{\text{dk}} + |V| \cdot T_{\text{em}})$ in general where $T_{\text{dk}}$ and $T_{\text{em}}$ are the time complexities of decreasing a key and extracting the minimum respectively
    \item $O(|E| + |V| \log |V|)$ with a data structure like Fibonacci heap where $T_{\text{dk}}$ is $O(1)$
    \item $O((|E| + |V|) \log |V|)$ with a data structure like binary search tree where $T_{\text{dk}}$ is $O(\log |V|)$
\end{itemize}

\subparagraph{Modified} Only for graphs without negative cycles

Time complexity: $O(|E| \log |E|)$ with a data structure like binary heap with lazy deletion
