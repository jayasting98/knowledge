\subsection{Union-Find Disjoint-Set (UFDS)}

The data structure is initialized to have a parents list and a ranks list. The rank is an upper bound of the height of the tree. Each set is initially its own parent and has a rank of 0.

\subsubsection{Find}

Path-compression is used when finding the set.

Time complexity: $O(\alpha(n))$ (amortized)

where $\alpha(n)$ is the inverse Ackermann function
